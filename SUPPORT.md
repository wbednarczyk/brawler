# Support

Brawler is pre-1.0 software maintained on a best-effort basis.

Use public issues for reproducible bugs, build failures, documentation problems, and feature proposals. Include:

- app version or commit
- operating system
- clear reproduction steps
- expected behavior
- actual behavior
- relevant redacted logs, if available

Do not include API keys, license tokens, private signing material, raw app databases, personal investment notes, or unredacted logs in public reports.

Commercial support, hosted services, premium integrations, or official distribution infrastructure may be offered separately in the future.
