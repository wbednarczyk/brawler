# v0.53.0 — Market data foundation: EOD quotes, sectors, level-0 ratios

Epic: `e189379` · Design: [ADR 0067](../adr/0067-market-data-foundation.md) · Source selection: [ADR 0082](../adr/0082-market-data-source-selection.md) · Metrics engine: [ADR 0046](../adr/0046-quality-frameworks-quantitative.md). Non-normative (ADRs/canonical docs win on conflict).

Goal: automated EOD quotes with full history, company sector classification, market cap + level-0 market ratios via the derived-metrics engine. Unblocks the valuation arc, price alerts (v0.54), and the backtest/calibration north stars. **The app is an automaton — no manual import** ([ADR 0082](../adr/0082-market-data-source-selection.md)).

## Shapes (from ADR 0067/0082 — STOP-AND-ASK before deviating)

- `daily_quotes(company_id, date, open, high, low, close, volume)`, unique `(company_id, date)`, append-only; upsert by key for corrections.
- **Primary** `yahoo-eod`: `query1.finance.yahoo.com/v8/finance/chart/<ticker>.WA` (keyless, PLN; `period1=0` full backfill, `range=5d` daily). **Secondary**: none — `twelvedata-eod` was implemented and then removed 2026-07-14 (GPW is paid-plan-only on Twelve Data; ADR 0082 amendment, card `ee81afe`). **Witnesses** (compare-only): BiznesRadar `/notowania`, Bankier, StockWatch. Ticker→provider mapping verified against the real watchlist in §T6; unmapped surfaces as source-health, never silent.
- Company registry gains `sector` (+ `sector_source: registry | manual`); the KPI-definition `sector` scope keys off the same taxonomy strings.
- Level-0 ratios as `canonical`-scope derived-metric definitions: market cap, P/E, P/BV, EV/EBITDA, dividend yield, FCF yield, 52w high/low distance, own-history percentile. Each value traces to (quote date + input facts).
- Decision-support: no cheap/expensive verdicts anywhere in copy.

### T2 — Fetch + parse + jobs (automaton)

## Tripwires
- Yahoo adds crumb/cookie auth or 429s ⇒ TD fallback must already be wired (T2), never a silent gap; kill-switch → source-health.
- NewConnect / edge tickers unmapped on `.WA` ⇒ flag + TD attempt, never silent.
- Temptation to compute ratios at query time from the whole corpus ⇒ STOP (persisted/indexed reads only).
- Any intraday/realtime scope ⇒ STOP (explicit non-goal).
- Sector field absent from the registry page ⇒ STOP-AND-ASK, fall back to witness + manual, do not invent.
