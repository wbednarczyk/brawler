# v0.53.0 — Market data foundation: EOD quotes, sectors, level-0 ratios

Epic: `e189379` · Design: [ADR 0067](../adr/0067-market-data-foundation.md) (decided) · Metrics engine: [ADR 0046](../adr/0046-quality-frameworks-quantitative.md).

Goal: Stooq EOD quotes with full history, company sector classification, market cap + level-0 market ratios via the derived-metrics engine. Unblocks the valuation arc, price alerts (v0.54), and the backtest/calibration north stars.

## Shapes (from ADR 0067 — STOP-AND-ASK before deviating)

- `daily_quotes(company_id, date, open, high, low, close, volume)`, unique `(company_id, date)`, append-only; upsert by key for corrections.
- Stooq per-ticker daily CSV `https://stooq.pl/q/d/l/?s=<ticker>.pl&i=d` — ticker mapping from the exchange-qualified ticker (GPW/NewConnect suffix rules verified against the maintainer's real watchlist in §T6; unmapped tickers surface as a source-health warning, never silent).
- Company registry gains `sector` (+ `sector_source: registry | manual`); the KPI-definition `sector` scope keys off the same taxonomy strings.
- Level-0 ratios as `canonical`-scope derived-metric definitions: market cap, P/E, P/BV, EV/EBITDA, dividend yield, FCF yield, 52w high/low distance, own-history percentile. Each value traces to (quote date + input facts).
- Decision-support: no cheap/expensive verdicts anywhere in copy.

## Tasks

### T1 — Data model + adapter descriptor
Migrations (`daily_quotes`, sector columns); `stooq-eod` source descriptor (new `market_data` source type) in `src-tauri/src/source_adapters/registry.rs` with rate-limit + policy note per ADR 0067. **Note: this milestone precedes the v0.55 `Fetcher` trait — implement fetch the existing bespoke way (own module + `source_refresh` dispatch arm) and leave a `// migrates to Fetcher (ADR 0069)` marker; do not pre-build the trait.** Contracts/data-model docs same change.

### T2 — Fetch + parse + jobs
CSV parser (header drift tolerated, locale-safe number parse — golden `insta` + proptest no-panic fuzz per ADR 0049); durable-queue jobs: `quote_backfill` (full history on company add / on enable, throttled, per-source serialization) and `quote_daily_pull` (post-session schedule via the existing scheduler; skips non-session days silently). Worker-lane decision: source-refresh lane (shared host lock). Tests: deterministic job tests (`run_until_idle`), backfill idempotence (re-run adds nothing).

### T3 — Sector ingestion + override
Populate `sector` from the GPW/NewConnect directory data during registry refresh where present (verify actual field availability first — **STOP-AND-ASK with findings if the registries expose no sector field**; fallback then: manual-only + aggregator witness proposal); manual override in the company metadata editor (`sector_source: manual` wins, never overwritten by refresh). Tests: refresh-does-not-clobber-manual.

### T4 — Level-0 ratios + market cap
Seed canonical derived-metric definitions over quotes × confirmed facts (`shares_outstanding` exists per ADR 0027); evaluation reads the latest close ≤ as-of date. 52w stats + own-history percentile computed from `daily_quotes` (indexed query, not corpus recompute — DoD §C). Tests: formula unit tests with known fixtures, golden snapshot of the ratio set, behavioral scale gate for the percentile query at volume.

### T5 — UI: price context in the company workspace
Fundamentals-adjacent price section: close + change, 52w range, ratio readout (InfoGrid), price history `TrendChart` (reuses the existing primitive; dataviz skill at implementation). Quote staleness shown via fetched-at attribution. Commands + DTOs + mock-runtime + fidelity steps; narrow-viewport assertion; empty state for no-quotes (unmapped ticker → link to source health).

### T6 — Real-data validation + closure
Ticker mapping validated against the maintainer's full real watchlist (every tracked company maps or is explicitly flagged); ratio spot-check vs an independent public source for 3 companies recorded in the epic. Journey: extends J3 (onboarding: quotes backfill automatically) and J1. Docs closure + wiki page.

## Tripwires
- Stooq response shape/ToS surprises (auth walls, rate-limit pushback) ⇒ STOP-AND-ASK — adapter swap is an owner decision (ADR 0067 anticipates it).
- Temptation to compute ratios at query time from the whole corpus ⇒ STOP (persisted/indexed reads only).
- Any intraday/realtime scope ⇒ STOP (explicit non-goal).
