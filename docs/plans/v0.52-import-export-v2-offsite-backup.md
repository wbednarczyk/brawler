# v0.52.0 — Import/export v2 (unified bundle) + offsite backup

Epic: `8e80b12` · Design: ADR to be written in §T1 · Backup boundary: [ADR 0032](../adr/0032-search-and-backup-boundaries.md) (2026-07-03 update).

Goal: one unified, versioned data bundle covering every owner-durable feature (closing the per-feature gaps, incl. financial facts + KPI definitions deferred from v0.37 and the v0.51 judgment entities), plus rotating backups to a user-chosen offsite folder.

## Pre-decided design (ratify in §T1's ADR; STOP-AND-ASK before deviating)

- **Bundle format v2**: a single JSON file with a `manifest` (bundle version, app version, created-at, section list with per-section schema versions and row counts) and named **sections**. Sections are self-contained and independently importable. Existing v1 exports remain importable (v1 detected by manifest absence and routed through the current path — no breaking change).
- **Section registry**: export/import implemented against a registry of section handlers (`id`, `schema_version`, `export(fn)`, `preview(fn)`, `apply(fn)`), so a new feature adds one handler — not edits across a monolith. Target sections at v0.52: companies, watchlists+memberships, notebook entries, claims, research (questions/evidence/briefs/digests/reminders), financial facts + KPI definitions + relevance, quality frameworks + custom metrics (fold the existing v0.44 export in), decision entries + report expectations, settings (non-secret, YAML stays for settings only per product-spec), cockpit layouts.
- **Import preview before apply** (existing UX rule): per-section counts + conflicts (existing-id collisions); apply is per-section opt-in; conflict policy `skip-existing` (no merge/overwrite in v2 — record as explicit non-goal).
- **Secrets never leave the keychain**; exports carry no API keys, license tokens, logs, or diagnostics.
- **Offsite backup**: a new setting — destination folder (picked via the existing Tauri save/dialog flow) + enabled flag + retained-copies count. On each successful local rotating backup (ADR 0032 machinery), the same artifact is copied to the destination with the same rotation; failure to copy **warns** (source-health style) but never blocks the local backup. No cloud APIs — local filesystem path only.
