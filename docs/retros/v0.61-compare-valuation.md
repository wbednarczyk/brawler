## App domain

**Went well**
- Substrate reuse paid off exactly as planned: `MultiLineChart` took the overlay unchanged; `fundamentals_coverage`/`company_health`/provenance validation states composed into the confidence grade without new plumbing; the level-0 ratio path fed peer multiples with no formula re-derivation.
- Designing the read model as N-companies-from-day-one made the Fundamentals periods table (N=1) and the late Profil view pure-frontend additions — `metricKeys[]` absorbed the owner's biggest scope amendment with zero Rust changes.
- The A0 real-data spike shaped honest design before code: thin peers are the norm (2/34 sectors reach N≥4), so the thin state was built as the primary state, not an edge case; the alignment ground truth reproduced 3/3 exact on first implementation.
- UX journey J6 got materially shorter: peer context + relative valuation now in-app (was: manual spreadsheet work).

**Went wrong / unexpected gaps**
- **MCP-written qualitative verdicts were user-unreachable since v0.60** — `set_qualitative_verdicts` existed but `QualityPanel` hard-coded "Not assessed yet". Found only by B4's explicit render-verification step; fixed RED-first with a standing guard test. Lesson: a write capability's DoD includes rendering proof, not just the write path. *(closed)*
- The approved storyboard led with the trend mental model; the owner's actual model (profile table: all KPIs × 2 companies at one period) surfaced only at live dogfooding → A7 amendment wave (Profil default, button removed). Mockup-first worked, but the storyboard never asked "which view is the default mental model?". *(closed; process lesson below)*
- Data-driven display names escape the translation guard: KPI names rendered raw English ("Current assets"). Fixed + `localizedKpiLabel` rule in ui-authoring + pl-locale tests. *(closed)*
- Diagnostics reconciliation chip painted over the ticker (grid track sized to the shortest label; Polish label 151px vs 90px cap — Polish-only bug). Fixed + class rule + bounding-box spec. *(closed)*
- Read model over-flagged NULL-currency ratio cells as `currency_unknown`; A7 worked around it frontend-side before B4 fixed it at source. *(closed)*
- Audit partial: `ensure_fx_backfilled` (backfill-on-first-need) has no production caller — daily job covers backfill functionally; card `ad27483`. *(still-open, low)*
- Valuation DTO carries no currency field (cosmetic PLN suffix; matters when US/EU adapters land) — noted on epic `fabd80f`. *(still-open, low)*

**Stop doing**: sizing grid tracks from the shortest label variant; rendering `def.label` raw; treating write-capability slices as done without a render path.

**Improve**: storyboard template should force the "default view / mental model" question for multi-view surfaces; sector taxonomy fragmentation (software split across 3 registry names) limits peer depth — `sector_source=manual` exists when the owner wants to consolidate.
